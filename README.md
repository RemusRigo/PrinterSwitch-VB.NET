# PrinterSwitch
PrinterSwitch: a system tray tool to select the default printer



## Author

* [@remusrigo](https://github.com/RemusRigo)
* [@remusrigo](https://sourceforge.net/u/remusrigo/profile)



## Features

* Tray icon menu with all installed printers; the default printer is checked and shown in bold
* Click a printer to make it the default printer
* Auto Refresh: rebuild the printer list every time the menu opens
* Rebuild menu on demand (after you add or remove a printer)
* Uses SetDefaultPrinter (winspool.drv)
